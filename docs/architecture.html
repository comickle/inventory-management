Customer orders with line items. Status flows: Processing → Shipped → Delivered.

Predicted vs current demand per SKU. Used to detect future shortages.

Backlog Item

Unfulfilled orders due to insufficient stock. Linked to purchase orders.

Key Architectural Patterns

Singleton Composables

  • Filter state shared across all views via useFilters.js
  • Module-level refs — no Vuex or Pinia needed
  • Watch on filters triggers automatic data reload

Compute-on-Read

  • All filtering happens at request time in Python
  • No pre-computed aggregations or caching
  • Dashboard KPIs computed from filtered slices

Pydantic Validation

  • All responses typed via response_model
  • Auto-generates OpenAPI schema at /docs
  • Type coercion + serialization handled automatically

CORS (Dev Mode)

  • Frontend (:3000) calls backend (:8001) cross-origin
  • Currently allow_origins=["*"]
  • Must restrict to frontend domain in production
